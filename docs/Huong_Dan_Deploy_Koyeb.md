## 🚀 QUY TRÌNH TRIỂN KHAI 3 BƯỚC (DƯỚI 3 PHÚT)

### BƯỚC 1: TẠO KHO LƯU TRỮ TRÊN GITHUB (30 GIÂY)
1. Đăng nhập vào [github.com](https://github.com).
2. Bấm vào dấu **`+`** ở góc trên cùng bên phải ➔ Chọn **New repository**.
3. Điền thông tin:
   - **Repository name:** `queen-stone-web` (hoặc tên tùy thích).
   - Chọn **Public** (Công khai) hoặc **Private** (Riêng tư) đều được.
   - **LƯU Ý:** Không tích chọn *"Add a README file"*, *"Add .gitignore"* (để kho trống).
4. Bấm **Create repository**.
5. Sao chép (Copy) đường link HTTPS của kho (Ví dụ: `https://github.com/MikeLam/queen-stone-web.git`).

---

### BƯỚC 2: CHẠY KỊCH BẢN ĐẨY CODE TỰ ĐỘNG (30 GIÂY)
1. Trong thư mục dự án trên máy tính, Anh bấm đúp chuột vào file:
   👉 **`Day_Len_Github.bat`**
2. Dán đường link GitHub vừa sao chép ở Bước 1 vào cửa sổ rồi nhấn **Enter**.
3. Kịch bản sẽ tự động:
   - Đóng gói toàn bộ 24 phiến đá, 80 ảnh Album công trình, và CSDL `queen_stone.db`.
   - Đẩy toàn bộ mã nguồn lên nhánh `main` của GitHub.
   - Tự động mở trang [app.koyeb.com](https://app.koyeb.com) trên trình duyệt cho Anh.

---

### BƯỚC 3: KẾT NỐI VÀ DEPLOY TRÊN KOYEB (1 PHÚT)
1. Trên trang **Koyeb.com**:
   - Bấm nút **"Sign up with GitHub"** (Đăng nhập 1 chạm bằng tài khoản GitHub, không cần tạo tài khoản mới).
2. Tại màn hình điều khiển (Dashboard):
   - Bấm nút **"Create App"** (hoặc **"Create Service"**).
   - Chọn nguồn triển khai: **GitHub**.
   - Chọn repository **`queen-stone-web`** vừa đẩy lên.
3. Koyeb sẽ tự động đọc tệp `Dockerfile`:
   - Môi trường: Docker container tự động nhận diện.
   - Port: `8000` (đã được cấu hình tự động tương thích).
   - Region: Chọn **Singapore (SIN)** hoặc **Frankfurt (FRA)** để tốc độ về Việt Nam nhanh nhất.
4. Bấm nút **"Deploy"**.
5. Hệ thống sẽ tiến hành build trong khoảng 1–2 phút. Khi trạng thái chuyển sang **`HEALTHY` (Xanh)**:
   - Koyeb sẽ cung cấp một đường link chính thức (Ví dụ: `https://queen-stone-mikelam.koyeb.app`).
   - Anh chỉ việc copy link này gửi cho khách hàng và đối tác trải nghiệm!
